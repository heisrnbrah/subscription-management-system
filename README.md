# BrightFlow — Subscription Management System

Hackathon prototype for the Odoo x Make-A-Ton 9.0 Kochi Hackathon 2026.

## Concept

BrightFlow is a unified subscription lifecycle platform covering:

- Products & variants
- Subscription plans
- Quotations
- Customer subscriptions
- Recurring invoices
- Payments
- Discounts & taxes
- Revenue reporting
- Customer portal
- Renewal management

## Current prototype

This repository currently contains the initial frontend dashboard prototype.

### Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Planned architecture

Frontend: React + Vite  
Backend: Node.js + Express + TypeScript  
Database: PostgreSQL + Prisma  
Authentication: JWT + bcrypt  
Validation: Zod
